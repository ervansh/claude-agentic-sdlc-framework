# Manual accessibility and browser checklist (IMP-012)

Record outcome (Performed / Not performed, with reason) in implementation-log.md. Axe cannot verify all WCAG 2.1 AA criteria.

- [ ] Screen reader spot check (NVDA/VoiceOver): error summary announced, labels and hints read
- [ ] Real-device Safari (iOS) check
- [ ] Latest two versions of Chrome, Edge, Firefox, Safari
